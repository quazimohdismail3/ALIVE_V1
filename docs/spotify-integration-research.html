Critical Reality Check

Spotify API Constraints — Know This First

⚠️ Audio Features & Recommendations: DEPRECATED Nov 27, 2024

Spotify removed access to /v1/audio-features, /v1/audio-analysis, and /v1/recommendations for all apps created after November 27, 2024 without advance notice. Apps that relied on these for BPM-matched wellness, meditation, and mood playlists were broken immediately.

  • Extended access now requires 250,000+ monthly active users (updated May 15, 2025)
  • Mission Alive currently has 0 active users → cannot apply for extended access
  • There is no formal process for startups/early-stage apps to get this access
  • Workaround: Essentia.js (open source, browser-based audio analysis) can replace Spotify's feature extraction

⚠️ Web Playback SDK: Sandboxed Audio Context

Spotify's Web Playback SDK runs in an iframed context. You cannot tap into the audio stream with Web Audio API. This means you cannot layer binaural beats, breath guides, or stems on top of the Spotify audio in the same audio graph.

  • Workaround: Run Mission Alive's synthetic layers (binaural, breath, stems) as a separate audio output channel
  • User hears both simultaneously — they mix in the air/headphones, not in code
  • This is actually how professional music therapists work anyway (layered intent)
  • Spotify Premium required for full Web Playback SDK. Free users → 30s previews only.
✅

ISO-Driven Track Selection Logic

ENTRAIN (0–8 min) — Match Current State

ISO principle: start where the user IS, not where you want them to go. Track selection targets the user's measured ANS state.


Target params: tempo ≈ hrv_bpm · energy ≈ affect_arousal · valence ≈ affect_valence · instrumentalness > 0.8

Example: HRV shows stressed user (arousal=0.8, valence=-0.2) → find tracks: 85–95 BPM, high energy, minor key, acoustic, fully instrumental. User immediately feels recognized.

Selection method: Pre-curated playlist OR Essentia.js-analyzed local catalog. No Recommendations API needed.

SHIFT (8–20 min) — Bridge Toward Target

ISO bridge: alpha coefficient increases as ANS direction is confirmed. Track selection gradually shifts toward therapeutic target over 3–4 tracks.


ISO bridge formula: target_energy = current + α × (therapeutic_target - current) where α ramps from 0.0 → 0.6 over 12 minutes

Example: Stressed user → calm target. Track sequence: 90 BPM → 75 BPM → 65 BPM. Energy 0.8 → 0.5 → 0.3. Gradual, not abrupt.

Crossfade timing: At track transitions (every 3–5 min), check HRV. If ANS moving in target direction → continue shift. If not → hold or slow the shift rate.

INTEGRATE (20+ min) — Hold Target State

User has arrived at therapeutic target. Tracks maintain achieved state. Binaural beats shift to integration frequency (theta 4–8 Hz for deep calm, alpha 8–12 Hz for relaxed alertness).


Target params: tempo = 55–70 BPM · energy = 0.1–0.35 · valence = 0.4–0.7 · acousticness > 0.7

Preferred genres: Ambient, classical (solo piano/strings), nature-infused, post-rock (slow). Filter by keyword search if Recommendations unavailable.

Invariant: Never play energizing tracks in INTEGRATE phase even if HRV fluctuates. State consolidation requires consistency.

Practical Solution

Track Curation Strategy (No Extended API Needed)

Since we can't use the Recommendations API at current user scale, here's how to build the catalog manually.

🎼

Phase 1: Manual Curated Playlists (Now)

Create 9 Spotify playlists (3 session types × 3 phases: ENTRAIN/SHIFT/INTEGRATE). Each 30–50 tracks. Analyze with Essentia.js to verify BPM/mood match. Hardcode playlist IDs in app config.

Session types: Morning Activation · Calm Recovery · Deep Focus

🤖

Phase 2: Essentia.js Runtime Analysis

User plays a track. Essentia.js extracts: BPM, key, mode, danceability proxy, mood. Compare to HRV-derived target. Reject if mismatch > 20%. Queue next track. No Spotify API needed for feature extraction.

👤

Phase 3: User's Own Spotify Library

Pull user's top tracks / saved tracks (basic API). Run Essentia.js on them. Build personalized ISO-mapped catalog. Feels deeply personal — it's their own music, curated by their HRV.
