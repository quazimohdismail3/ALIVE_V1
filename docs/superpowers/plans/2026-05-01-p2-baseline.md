# P2 Implementation Plan — Baseline Engine + Calibration HRV Persistence

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Bayesian personal baseline engine (cold-start → blended → personal), wire quality gates on session eligibility, persist calibration sessions as baseline data, and surface baseline state in the Calibration UI per psyche §3.5.

**Architecture:** Pure-function `baseline_engine.py` (no I/O) drives all math. `db.py` gets 4 new async helpers. A new `/api/baseline` endpoint recomputes on demand. `hrv_processor.py` gains 3 quality scalars (`artifact_rate`, `mean_sqi`, `hr_drift_bpm`). `rf_calibration.py` harvests final HRV at `cal_done`, runs `quality_check`, and optionally persists + recomputes baseline. `Calibration.jsx` gains psyche §3.5 panels: HR-inside-orb, faded HRV overlay (n_rr ≥ 30 gate), one-time hint, and baseline-updated end state.

**Tech Stack:** Python + asyncpg + Supabase, FastAPI, React + Vite, pytest-asyncio.

**Reference spec:** `docs/superpowers/specs/2026-04-30-h10-gold-standard-design.md`
**Design language:** `~/.claude/projects/C--Users-user-Desktop-mission-alive/memory/reference_psyche-design-language.md`

**Gate:** cold-start fixture suite passes (≥18 tests), `quality_check` rejects all 5 bad fixtures, Bayesian posterior verifiable, calibration psyche §3.5 shipped, first H10 calibration graduates user cold→blended.
